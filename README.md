A tiny Python program whose entire output is exactly one line: one original one-liner about the perils of cloning yourself to skip work — duplicating yourself doubles the worker but halves the deniability when HR comes asking. Deterministic: the same line on every run, with no randomness, no network access, and no clock dependence.

## Run it

```sh
python3 main.py
```
